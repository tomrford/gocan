# ZLG libraries

These are binaries from Guangzhou ZHIYUAN Electronics (ZLG), included unchanged
so gocan can drive ZLG adapters without a separate ZLG installation. They are
ZLG's, not covered by gocan's licence.

The files are identical to the x64 `zlgcan` package of
https://github.com/jesses2025smith/zlgcan-driver at `3040548`.

The libraries need the Microsoft Visual C++ 2008 SP1 x64 redistributable, and
`USBCANFD.dll` also the Visual C++ 2013 x64 redistributable; neither is
included.
